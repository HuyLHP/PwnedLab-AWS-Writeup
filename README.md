# PwnedLab AWS Security Writeups
Đây là writeup ghi lại quá trình học tập và thực hành các kỹ thuật tấn công bảo mật AWS cloud. Mỗi bài lab bao gồm bối cảnh thực tế, hướng dẫn từng bước và các bài học rút ra.

> **Lưu ý:** Nội dung này chỉ phục vụ mục đích học tập. Tất cả bài thực hành được thực hiện trong môi trường lab được cấp phép bởi PwnedLab.
