## Real-world context
Khi xây dựng cơ sở hạ tầng trên AWS, thực hiện kiểm tra, xây dựng các quy trình ứng phó sự cố, hay đánh giá tính bảo mật cho các môi trường AWS, đôi khi các công cụ sẵn có không đáp ứng chính xác những gì chúng ta cần. Trong những trường hợp như vậy, khả năng tự tạo ra các công cụ và script riêng sẽ giúp chúng ta xây dựng, phòng thủ và tấn công một cách hiệu quả hơn.
## Walkthrough
Để chuẩn bị môi trường lập trình cho bài học, chúng ta cần thực hiện các bước sau:
- **Cài đặt phần mềm:** Tải và cài đặt Burp Suite (Community Edition), AWS CLI, cùng với Visual Studio Code (cài kèm extension Python và Python Debugger).
- **Cấu hình Burp Suite:** Thêm file Jython standalone vào phần mềm, sau đó vào BApp Store cài đặt extension **Copy As Python-Requests** để có thể sao chép trực tiếp các request thành script Python.

Trước hết, chúng ta nhập thư viện `requests` – thư viện cần thiết để Python có thể thực hiện các yêu cầu HTTP. Tiếp theo là biến `burp0_url`, đây chính là URL mà AWS CLI sử dụng khi cố gắng truy cập vào bucket. 

Trong URL này, chúng ta cần lưu ý đến giá trị prefix để sử dụng sau đó. `burp0_headers` là các header được sử dụng trong yêu cầu; dù không thực sự quan trọng trong trường hợp này, nhưng để đơn giản, chúng ta cứ giữ nguyên chúng. Cuối cùng, `requests.get...` được sử dụng để thực hiện yêu cầu HTTP tới `burp0_url`.

Giống như với Burp và AWS CLI, bây giờ chúng ta có thể xuất ra các thư mục có sẵn bên trong bucket. 

Việc chèn các thư mục của chúng ta vào giá trị **prefix** sẽ cho phép chúng ta xem thêm thông tin bổ sung, điều mà chúng ta thực hiện bằng cách thêm một biến URL mới có tên là `new_url`. Chúng ta thêm chữ `f` vào trước URL của mình để có thể sử dụng các biến bên trong dấu `{ }`, điều mà chúng ta làm với biến `prefix` từ vòng lặp `for` mà chúng ta đã tạo.

Sau đó, chúng ta thêm một biểu thức chính quy (regular expression) khác để phân tích (parse) từng thư mục có thể truy cập để lấy các **key**, rồi in thông tin đó ra terminal.

Chúng ta cũng có thể thêm lại một số câu lệnh `if`, `elif`, `else` để xử lý trường hợp output mà chúng ta không có quyền truy cập. Đoạn code đã được cập nhật trông như sau với các **key** đã được in ra. Lưu ý rằng tôi đã xóa bớt một số câu lệnh `print` trước đó để bắt đầu làm sạch gọn phần output.
![](99.assets/05.Create%20Custom%20Tooling%20to%20Explore%20AWS-16.png)
Cuối cùng, chúng ta có thể thêm chức năng tải xuống các tệp từ bucket về local directory. Đầu tiên, hãy thêm `import os`, vì chúng ta sẽ cần tạo một thư mục mới để các tệp được tải xuống. Ngoài ra, hãy thêm một biến mới có tên là `directory_name`, chúng ta có thể gán nó bằng `dev.huge-logistics.com`.
```python
import requests
import re
import os
import urllib3
urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)
bucket_url = "https://s3.amazonaws.com/dev.huge-logistics.com?list-type=2&prefix=&delimiter=%2F&encoding-type=url"
directory_name = 'dev.huge-logistics.com'
response = requests.get(bucket_url)
if response.status_code == 200:
    prefixes = re.findall(r'<Prefix>(.*?)</Prefix>', response.text)
    print('Directories discovered:')
    for prefix in prefixes:
        if prefix == '':
            print('/')
        else:
            print(prefix)
        new_url = f"https://s3.amazonaws.com/dev.huge-logistics.com?list-type=2&prefix={prefix}&delimiter=%2F&encoding-type=url"   
        response = requests.get(new_url)
        if response.status_code == 200:
            keys = re.findall(r'<Key>(.*?)</Key>', response.text)
            for key in keys:
                if key == prefix:
                    pass
                else:
                    print(f'File Discovered - {key}')
                    download_url = f'https://s3.amazonaws.com/dev.huge-logistics.com/{key}'
                    print(f'Downloading {key}')
                    file_response = requests.get(
                        download_url, stream=True, verify=False)
                    if file_response.status_code == 200:
                        if not key.endswith('/'):
                            file_path = os.path.join(
                                directory_name, key)
                            os.makedirs(os.path.dirname(
                                file_path), exist_ok=True)
                            with open(file_path, 'wb') as file:
                                for data in file_response.iter_content(1024):
                                    file.write(data)
                                print(f'{key} downloaded.')
        elif response.status_code == 403:
            print('We do not have permissions to access this directory.')
        else:
            print('Something is causing us to not be able to access the bucket.')

elif response.status_code == 404:
    print('Bucket does not exist.')
elif response.status_code == 403:
    print('We do not have permissions to access this bucket.')
else:
    print('Something is causing us to not be able to access the bucket.')
```
